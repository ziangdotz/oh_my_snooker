# 浏览器验证产物

此目录只保留当前src及冻结PCOL对照所需的浏览器验证输出，运行和构建不读取这些文件。

testing下按测试主题保存截图、状态、报告及失败诊断。场景对照位于testing/designs/interior-design-ID/scene，玩法对照位于对应regression目录；单墙对照位于testing/modern-wall-study。测试重复执行时更新同一主题，不建立版本存档。

工程和专项JSON结果位于reports。执行命令见[开发流程](../docs/development/workflow.md)，产物规则见[说明](../docs/development/artifacts.md)。
