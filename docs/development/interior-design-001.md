# 室内设计001

当前主题为暖木俱乐部，保留认可纹理、窗门、灯光、挂画安装与家具连接。共用实现与验证见[设计系列](interior-design-collection.md)。

## 空间与设计

房间约13×12米、净高3.35米。球台位置、相机、原始灯光、物理与规则均保留。前墙沿用原抽象画，侧墙保留球杆架，后侧为卡座、双圆桌与右后入口。

| 元素 | 当前实现                                                           |
| ---- | ------------------------------------------------------------------ |
| 墙面 | 暖米灰`#e0d4bd`，细矿物涂层纹理                                    |
| 护墙 | 橄榄绿`#4d5741`，细暖铜压条                                        |
| 木作 | 蜂蜜橡木贴图与受控染色；长条地板、天花格栅、后墙木条与茶几         |
| 软包 | 五段米白亚麻座垫和靠垫，所有轴向倒角，细前缘缝线                   |
| 布局 | 茶几中心z=6.65，接近卡座；地毯收进后侧，入口通道留空               |
| 照明 | 更暖的环境光、洗墙、下照、窗边与壁灯补光；双线性灯具补齐吊线安装盘 |
| 窗门 | 两处三分格窗体、深窗台和玻璃；右后单扇门配门框、铰链、锁柄及门槛   |
| 构造 | 卡座补承托框和地毯上支脚，茶几补安装盘；画框配背衬与支架画灯       |

木纹、涂层和织物按世界尺度展开UV，软包圆角保留各表面投影方向。静态几何按材质和投影职责合并，软包与硬质支架共同参与室内阴影。所有新增装饰禁用拾取和碰撞，重复应用保留幂等保护。

## 源码与使用

独立装配为`src/presentation/scenes/interior-design-001.js`，同目录的`interior-geometry.js`与`interior-finishes.js`提供软包和纹理工具。图片引用由runtime-catalog登记。

运行`node src/start.mjs`后打开http://127.0.0.1:5173/?interior=interior-design-001，或使用INTERIOR DESIGN。场景截图和报告位于artifacts/testing/designs/interior-design-001/scene。修改遵循[开发流程](workflow.md)。

## 渲染边界

独立`interiorDesign001`shader继续处理旧引擎阴影精度与聚光边缘，不修改第三方引擎、原shader或球台材质。新增八盏暖色灯只包含室内网格，主下照和休息区洗墙光分别产生软阴影。原球体探针不等于新房间的完整实时反射。当前实现以实际材质、几何和布局为依据。
